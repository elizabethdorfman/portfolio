The site loads `david-optimized.stl` on tablet and desktop: 65,000 triangles, 3.25 MB (about 94% smaller).
Phones load `david-mobile.stl`: 12,000 triangles, 586 KB (about 99% smaller), preserving the silhouette while reducing first-load time.
Both are derived from the original 1,083,370-triangle CC0 scan using quadric mesh simplification.
The original david.stl is retained as the source asset.
